# BB Extension Sorter

Органайзер меню расширений SillyTavern. Помогает разложить расширения по папкам, перенести их между колонками и сохранить удобный порядок в настройках.

## Обновлённый интерфейс (v1.1.0)

- **Компактные папки:** высота строки 44 px вместо крупной карточки; заголовок в одну строку и обрезается многоточием, если не помещается.
- **Спокойный дизайн:** нейтральная поверхность без градиента и тяжёлых теней. Цвет папки используется только для иконки и тонкого акцента в редакторе.
- **Счётчик содержимого:** возле названия показывается количество реально загруженных в папку расширений.
- **Удобнее на телефоне:** единая высота строк, расширенные ручки перетаскивания, адаптивное окно сортировки.
- **Рабочие элементы:** раскрытие папки по строке и стрелке, управление клавишами Enter/Пробел, цвет и переименование в один ряд.

## Возможности

- **Папки** - создавайте группы расширений прямо в меню настроек.
- **Сворачивание** - папки можно раскрывать и скрывать кликом.
- **Цвета** - у каждой папки есть собственный цвет для быстрой навигации.
- **Drag-and-drop** - отдельное окно сортировки позволяет перетаскивать расширения между левой и правой колонкой или внутрь папок.
- **Сохранение раскладки** - структура сохраняется в настройках SillyTavern и применяется автоматически.

## Как пользоваться

1. Откройте настройки расширений.
2. Нажмите кнопку `Управление сортировкой`.
3. Создайте папки и перетащите расширения в нужные места.
4. Нажмите `Применить`.

## Установка этой модифицированной версии

Если оригинальное расширение уже установлено, **сохраните резервную копию** и замените в его каталоге файлы `index.js`, `style.css` и `manifest.json` файлами из данного архива. Перезагрузите страницу SillyTavern. Существующая раскладка папок сохраняется: формат настроек не менялся.

При ручной установке с нуля скопируйте папку расширения в `public/scripts/extensions/third-party/BB-Extension-Sorter` внутри SillyTavern и перезагрузите приложение. Не устанавливайте две копии органайзера одновременно — они используют одни и те же настройки и элементы интерфейса.

## Установка оригинальной версии

1. Откройте SillyTavern.
2. Перейдите в `Расширения -> Установить расширение`.
3. Вставьте ссылку на репозиторий:
   `https://github.com/maxkara14/BB-Extension-Sorter`
4. Перезагрузите страницу.
5. Нажмите `Управление сортировкой` над списком расширений.
